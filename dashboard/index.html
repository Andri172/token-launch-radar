How a row is priced — model

A pre-token protocol is priced against the protocols in the same snapshot whose tokens already trade. For each category, the live protocols' market cap / TVL ratios give a base multiple (the median, winsorized to [0.02, 3] and shrunk toward the global median so thin categories cannot dominate). Implied value = TVL × base multiple × momentum × maturity × breadth: momentum damps the 7-day TVL change, maturity rewards time already run with no token, breadth adds a small premium per extra chain. A separate launch score (0–100) weighs the category's own token propensity, the protocol's scale, age band, chain breadth and momentum; expected value is implied value weighted by that score. No protocol name is special-cased — the same function prices every row, and live-token protocols are never mixed into the board: they are the evidence, shown under Comparables.
